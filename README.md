# SoundStar

Sitio web de reseñas y novedades musicales. Permite ver reseñas de discos, conocer su contenido y ponerse en contacto.

## Descripción

SoundStar es un sitio web estático desarrollado para el Trabajo Final Integrador de la materia. Cuenta con tres páginas: inicio (con carrusel de imágenes), reseñas de discos organizadas en columnas, y un formulario de contacto con validación en JavaScript.
